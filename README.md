
# ✨ Nexa AI — AI Chat Interface

A modern, responsive AI chat interface built using HTML, CSS, and JavaScript.

## 🚀 Features

- 💬 Interactive chat interface
- ✨ Animated typing indicator
- 🗂️ Multiple conversations
- 🔍 Search conversation history
- 💾 Persistent chat history using Local Storage
- 📱 Responsive design for mobile and desktop
- ⚡ Quick prompt suggestions
- 🌙 Modern dark theme with gradient accents

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📂 Project Structure

```text
nexa-ai/
├── index.html
├── style.css
└── script.js
```

## 🏃 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/medhruva033/ai-chat-interface.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.

## ⚠️ Current Limitations

This project currently uses simulated AI responses. It does not connect to a real AI model or external API.
